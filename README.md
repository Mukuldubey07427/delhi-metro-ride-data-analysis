# Delhi Metro Ride Demand Analysis 🚇📊

## 📌 Project Overview

This project analyzes Delhi Metro ride data to understand passenger demand, station performance, ticket types, revenue and monthly ride trends.

The project follows a complete Data Analytics workflow:

**Raw Data → 🧹 Data Cleaning → 🗄️ SQL Analysis → 📈 Data Visualization 

---

## 🎯 Objectives

- 🚇 Analyze total metro rides and passengers
- 📍 Identify the busiest stations
- 🎫 Analyze ticket type usage
- 💰 Analyze revenue generated by different ticket types
- 📅 Study monthly ride and revenue trends
- 💡 Generate meaningful insights from the data

---

## 🛠️ Tools & Technologies

- 🐍 **Python**
- 🐼 **Pandas**
- 🔢 **NumPy**
- 📊 **Matplotlib**
- 🗄️ **PostgreSQL**
- 💻 **SQL**

---

## 🔄 Project Workflow

### 📅 Day 1 — Data Cleaning 🧹

The raw dataset was cleaned using Python.

Tasks performed:

- 🔍 Checked dataset shape and columns
- 🔍 Checked data types
- ❌ Identified missing values
- 🔄 Checked duplicate rows
- 🧹 Removed duplicates
- ✨ Cleaned text columns
- 📅 Converted date column to proper date format
- 📊 Handled missing passenger values
- 🎫 Handled missing ticket types and remarks
- ⚠️ Checked invalid and negative values

---

### 📅 Day 2 — SQL Analysis 🗄️

The cleaned dataset was imported into PostgreSQL for analysis.

SQL analysis included:

- 📊 Total rides
- 👥 Total passengers
- 💰 Total revenue
- 💵 Average fare
- 📏 Average distance
- 📍 Top stations by rides
- 👥 Top stations by passengers
- 🎫 Ticket type analysis
- 💰 Revenue analysis
- 📅 Monthly ride trends
- 📈 Monthly revenue trends

---

### 📅 Day 3 — Data Visualization 📈

PostgreSQL was connected with Python to visualize the SQL analysis results.

Charts were created using **Matplotlib**.

### 📊 Visualizations

1. 🚉 Top 10 Stations by Total Rides
2. 🎫 Rides by Ticket Type
3. 📅 Monthly Total Rides
4. 💰 Monthly Total Revenue
5. 🎟️ Revenue by Ticket Type
6. 👥 Top 10 Stations by Passengers

---

## 💡 Key Insights

- 🚉 **Rajiv Chowk** recorded the highest number of rides among the analyzed stations.
- 💰 **Tourist Card** generated the highest revenue among the ticket types in the dataset.
- 📅 Monthly ride demand remained relatively consistent, with some noticeable peaks and drops.
- 👥 Passenger volume was highest at the busiest stations.
- 🎫 Different ticket types showed different patterns in terms of rides and revenue.
